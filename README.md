# Lab Project 1 — Simulador de Fundos Imobiliários

Projeto desenvolvido em Excel para simular investimentos mensais em fundos imobiliários (FIIs).

## Funcionalidades

- Definição do aporte mensal, prazo e rendimento esperado.
- Cálculo do patrimônio acumulado usando a função VF.
- Estimativa dos dividendos mensais.
- Projeções para 2, 5, 10, 20 e 30 anos.
- Distribuição dos aportes entre seis tipos de FIIs conforme o perfil selecionado, utilizando PROCV.

## Funcionamento

O usuário preenche os campos de entrada e seleciona seu perfil de investidor. Os resultados são calculados automaticamente.

As entradas são utilizadas nas fórmulas financeiras para calcular o crescimento do investimento. Os intervalos nomeados facilitam a identificação dos valores nas fórmulas.

Os percentuais dos perfis são exemplos utilizados para fins educacionais, com distribuição total de 100%, e não representam recomendações financeiras.

## Personalização

A planilha foi simplificada com base no modelo apresentado nas aulas, mantendo os cálculos e as funcionalidades principais.

## Como utilizar

Baixe o arquivo `lab project 1.(1)xlsx`, abra no Microsoft Excel e altere os campos de entrada para visualizar os resultados.
